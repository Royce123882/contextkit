contextkit
==========

**Build context once. Send it anywhere. Know exactly what the model sees.**

contextkit is a context engineering SDK for building reliable AI agents.
It treats the context window as a first-class, engineerable artifact
with full observability, provenance tracking, and provider-agnostic
formatting.
